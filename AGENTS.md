# Cnote UI Work

Before changing any user-facing UI, read [`docs/design-system.md`](docs/design-system.md).

The canvas is the product surface, not a marketing page. New controls should reuse the existing Cnote menu, toolbar, node, and dialog patterns. Do not add explanatory feature cards, nested card stacks, browser-version affordances, or text-filled rounded buttons where an icon and tooltip are sufficient.
