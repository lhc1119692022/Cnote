# 视频素材传输

素材准备先于模型提交；任何准备失败都不创建视频任务。

- HTTPS 素材直接使用；不保证第三方地址可匿名读取。
- Data URL：仅在渠道文档明确支持时显式选择；808relay 工作台说明支持此方式，但不是全渠道默认能力。
- 自动：有供应商上传路径时使用预签名，否则使用已配置的自定义存储，均无配置时要求 HTTPS。历史已保存的上传路径保留，不猜测或切换供应商域名。
- 预签名：先申请，再 PUT，成功后使用读取 URL。
- multipart：向供应商上传路径发送 multipart，独立于视频协议。
- 自定义：沿用本地存储配置，不新增 R2 签名服务。

内联限制按编码后的 JSON UTF-8 总大小检查，包含 Base64 膨胀与提示词。准备错误使用 preparation 阶段，与 creation 区分。

## 有效期与清理

识别 X-Amz-Date / X-Amz-Expires 读取签名及素材 expiresAt（毫秒时间戳）；不足一小时拒绝提交，要求更新地址。未知有效期不猜测，用户需向存储服务确认保留时间。超过一小时的排队仍可能超期，本地检查不是服务端可用性保证。

保留本地原件。供应商托管文件由供应商保留策略管理；自定义存储继续使用本地存储页面的手动删除。不要在提交完成或停止轮询时删除远程素材；确认所有引用任务终态且不再重试后再清理。验证上传产生的测试对象也遵循此规则。暂不新增自动删除、桶生命周期修改或客户端限时上传许可。
