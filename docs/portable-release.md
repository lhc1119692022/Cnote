# Windows 免安装版

下载 GitHub Releases 中的 `Cnote-<版本>-win-portable-x64.zip`，解压到自己选择的可写文件夹，再启动其中的 Cnote 可执行文件。不要直接在压缩包里运行。

- 适用于 Windows x64；无需安装。
- 默认在可执行文件旁的 `CnoteData` 文件夹保存用户数据；自行更改存储目录后，以设置中的位置为准。
- 升级前退出程序，保留 `CnoteData` 和 `cnote-storage-location.json`，只替换程序文件。不要把新程序解压到另一个目录后误以为旧数据丢失。
- 打包不包含开发者的密钥、画布、浏览器登录信息或生成结果。首次使用需要自行配置渠道。
- 程序未进行代码签名，Windows 可能提示未知发布者。只使用本仓库发布的附件，并核对同一发布中的 SHA256 校验文件。
- 免安装启动器可能使用系统临时目录解包程序；不能承诺运行过程完全不占用系统盘。
- 不要向仓库提交或向他人发送 `CnoteData`、密钥文件、浏览器数据或配置导出。`.gitignore` 仅防止误添加，不能保护历史中已经提交的文件，也不能识别任意名称的自定义数据目录。

## 发布流程

桌面版本与 `v<版本>` 标签保持一致。推送标签后，Windows 发布工作流在干净的构建环境中运行检查，构建免安装程序，生成 ZIP 与 SHA256 校验文件，再上传到对应 GitHub Release。

发布附件通过代码检查不代表完整桌面体验已经验收。首次启动、配置渠道、打开旧画布、生成任务及关闭重开后的数据保留，仍需手动验证。
