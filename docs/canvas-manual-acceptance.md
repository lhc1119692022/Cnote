# 本轮交付后的桌面手动验收

## 状态与边界

本轮补齐 AI 实际流式传输和停止、顶栏添加入口，并修复媒体胶囊拖入自身预览与 Browser 焦点交接。代码和模拟回归通过，不代表以下桌面体验已通过。**本清单全部待用户手测**；没有启动或控制桌面，没有调用真实渠道或读取真实密钥。

当前用户确认的界面优先于旧版：顶栏菜单与空白处双击菜单有意不同。完整的 97d15d4 差异清单后置，不在本轮宣称严格兼容完成。此前手测记录保留为历史证据，不能替代当前版本验收。

## 准备与记录

- 完全退出旧桌面进程，再通过 start-cnote.bat 启动本轮版本；仅刷新页面不足以更新桌面网络与焦点桥接。
- 用测试 Flow 或现有 Flow 的副本，准备长文本、至少两张图片、两段视频和一个可访问网页。先做无需费用的操作；真实 AI / 生成测试由你自行决定是否发起。
- 按自己的使用流程测试即可，不必逐条机械执行。用下表查对应的通过标准；未做的项目保留“待测”，不以自动脚本结果代替。
- 失败反馈只需：操作步骤、节点类型、窗口/面板/zoom 状态、实际结果，以及一张截图或短录屏。首次不连续的位置优先处理。

## 批次结果、展开与解绑（本轮新增，待手测）

当前采用新规则：每次正式开始生成都创建新结果节点和一条连线；同一轮的所有成功输出进入该节点的资源列表。不会自动改造或覆盖旧版已有结果节点。

| 操作 | 通过标准 |
| --- | --- |
| 连续生成两轮，第一轮 1 张、第二轮 3 张 | 每轮各一个结果节点与连线，旧结果内容/位置保持不变；新节点避开已有节点。参数校验失败不创建空节点。 |
| 批量过程中观察输出 | 节点在任务启动后出现；成功图片逐项进入，按请求顺序排列，后返回的图片不抢走当前预览。状态显示完成数量；失败/取消不抹掉成功图片。 |
| 左侧点击“展开” | 所有成功图片在一个节点内部网格平铺；未结束位置保留占位。左侧图片切换胶囊消失，只剩“收起”“解绑”，生成中/待继续时解绑禁用。 |
| 在网格中选另一张，再点击“收起” | 恢复原节点尺寸和单图预览，保留刚选中的图片，左侧资源胶囊恢复；不改变画布 zoom 或搬动其他节点。 |
| 任务结束后展开并点击“解绑” | 原批次节点消失，成功结果各自成为独立节点，位置对应网格；全部上游连接断开，失败占位不会变成空节点。 |
| 解绑前连接一个下游 AI/生成节点并选择图片 | 展开前后，下游仍使用选中的图片而非整批；解绑后原输出连接归选中图片的独立节点，其他图片不被自动连给下游。 |
| 解绑后撤销一次，再重做 | 一次撤销完整恢复批次节点、网格状态、资源列表和连线；重做恢复独立节点。不产生重复图片。 |
| 批量尚未结束时离开再回来，继续任务；完成后关闭桌面重开 | 同一轮继续使用原节点，不重复添加已完成图片；列表、选中项、展开/收起状态保持。 |
| 复制结果节点，或锁定画布；断开/删除本轮结果后等待返回 | 副本不继续接收任务更新；锁定禁止展开尺寸变化和解绑。断开后不再写入该节点，删除后迟到结果不会自动重建节点。 |

本轮使用模拟网络和组件测试，没有提交真实付费生成或进行桌面手动验收。失败项重试继续沿用现有生成/续查入口，本轮不新增单格重试菜单。

## 第一段：打开画布、添加和整理内容（无需真实生成）

| 操作 | 通过标准 |
| --- | --- |
| 新建空 Flow，打开顶栏中间左按钮；再点右按钮 | 中心保持两个按钮。左菜单仅按顺序显示“添加内容节点”“添加请求体”“添加浏览器节点”；没有 AI、贴纸、资料库。右按钮直接创建 AI，不先打开菜单。窄窗口仍能使用两个入口。 |
| 空白处双击 | 仍是独立的三组菜单：①添加内容节点、添加 AI 节点、添加请求体、添加浏览器节点；②添加贴纸、导入文件；③内容资料库。顶栏调整不改变此菜单。 |
| 查看空画布与小地图；连续缩放和平移 | 空画布小地图视口居中、没有左下角偏移；背景点的大小、间距和位置保持固定，不随 zoom 变化。小地图视口随实际视图变化，无跳动。 |
| 创建贴纸，编辑、改色、调整大小、复制和删除 | 胶囊中选择颜色；正文只保留简单的一排格式操作；颜色/编辑结果保存，操作不误拖动节点，撤销可恢复。 |
| 导入长文本，展开和收起格式设置，再打开详情 | 节点格式工具默认隐藏，由胶囊设置控制；工具超宽换行，不出现横向工具滚动条。详情没有多余嵌套边框与“文本”角标；正文滚动不缩放画布。 |
| 在图片/视频多资源节点中，将第二个资源胶囊拖到本节点预览 | 预览切换到正确资源；节点与画布不移动；一次撤销恢复原资源、重做再次切换。点击和键盘激活胶囊仍有效。分别在 25%、100%、250% 和详情面板打开时测试。 |
| 拖到别的节点/空白处，或拖动中按 Escape、切出窗口 | 不误切换资源，不产生多余撤销步骤；取消后没有残留拖拽状态，下一次点击与拖动正常。 |
| 下载、拆分媒体；对解析失败/资源丢失的样本重识别或恢复 | 操作针对当前资源；拆分不丢来源与内容，能撤销；保存文件能实际打开。失败有明确提示、不冒充成功，不改坏原节点。 |

## 第二段：浏览网页和上游输入

| 操作 | 通过标准 |
| --- | --- |
| Browser 输入地址、前进/后退、刷新、网页内滚动 | 操作作用于网页；网页滚动不改变画布 zoom，地址栏编辑不会拖动节点。 |
| 先点网页，再点空白画布，然后操作快捷键 | 焦点回到主画布。先保存测试 Flow，再测试 Ctrl+R：不再单独刷新 Browser 内的网页。网页真正聚焦时仍保留网页自身快捷键。 |
| 从网页转到 AI 输入框、文本编辑器或顶栏输入框打字 | 输入进入点击的主界面输入框，不被网页吃掉；不因焦点修复丢失输入或选区。 |
| 捕获网页，生成 Content，再连到 AI | 捕获内容节点可查看且连线正确；上游取真实正文，不仅取标题。重开后内容和连线仍在。 |
| 对含文字/图片的上游，分别仅连线发送、插入胶囊发送 | 使用支持图片的模型时识别实际所选图片；两种输入方式均生效，同一图片不重复附加。断开/缺失资源有明确提示，而不是静默只传文件名。此项由用户自行进行真实渠道测试。 |

## 第三段：AI 连续聊天（真实请求可能收费）

| 操作 | 通过标准 |
| --- | --- |
| 配置渠道和模型；开关胶囊设置、新建/管理会话、系统提示词 | 默认隐藏模型/Web Search/思考强度；展开后后两者在输入框下方左侧，模型在右侧。胶囊相关入口可用；详情是同一聊天的放大视图，不是另一个会话。 |
| 请求较长的 Markdown 回复，同时观察节点和详情 | 支持流式的渠道在结束前逐段显示内容，不等完整回复后一次出现；两处内容同步，标题/列表/代码/表格按格式显示。渠道只返回 JSON 时允许一次显示，不伪造打字流。 |
| 生成时上滚阅读旧消息，再回到底部 | 上滚后不会被每段新输出强拉到底部；回到底部后可继续跟随，不带动画布滚动。 |
| 首字出现前停止一次；再在输出途中停止一次 | 发送位置可停止，无重复请求；停止后不再追加新内容，已生成片段保留。节点和详情任一处均可停止同一请求。 |
| 停止后重试；生成中离开 Flow 或删除该 AI | 重试不重复插入同一条用户问题；离开/删除中止原请求，不把迟到结果写进其他 Flow。删除后的撤销行为不产生孤立运行状态。 |
| 模拟无效配置/连接失败；恢复配置再发送 | 错误明确、按钮恢复可用，不无限转圈。停止或完成后关闭并重开，历史与已有片段仍可查看、继续聊天。 |

## 第四段：图片与视频生成（真实任务可能收费）

| 操作 | 通过标准 |
| --- | --- |
| 添加请求体，分别进入图片与视频生成 | 请求体只作选择中转；图片/视频分别展示对应能力，不把请求体本身混成生成节点。 |
| 在自己使用的站点拉取模型，配置参数和参考素材 | 返回实际可用模型，错误可读；模型/参数入口位于输入框底部左侧，与右侧发送按钮同排；无无意义的小图标。选中资源与参考输入一致。 |
| 分别提交图片/视频批量任务 | 进度与结果对应各任务；部分失败不覆盖成功结果，旧结果保留。生成按钮显示“生成中”和递增等待时间，悬停变红并显示“取消生成”。 |
| 取消任务；有可继续任务时离开再返回 | 生成、取消、继续使用同一主按钮位置；待继续显示“继续生成”，继续的是原任务而非重新收费提交。确认最终状态与渠道实际结果一致。 |
| 关闭桌面后重开并查看历史结果 | 图、资源选择、结果关联与历史不丢失；需要手动继续时有明确入口，不静默重发任务。 |

## 第五段：随使用流程穿插的画布验收

| 场景 | 通过标准 |
| --- | --- |
| 连接：预览、合法/非法目标、自环/重复、空白松手、选择和删除 | 预览与吸附明确；非法连接不落盘；空白松手有后续创建入口或明确取消反馈，无卡住状态。选中边可删除、撤销恢复，锁定时不能修改；节点移动/变大后端点准确。 |
| 多选复制、Alt 拖副本、编组、拖入、解绑、移动、删除 | 单节点轮廓或多选外接框间隔 40 世界像素；Alt 拖原件不动。中心命中 group 收纳，移动组成员同步、解绑保持位置；边关系不丢，结构变化可撤销重做。 |
| 逐类节点在 25%、50%、100%、150%、250% 下编辑与调整大小 | 内容和外框圆角对齐，无双边框/异常裁切；悬浮胶囊、连接点、手柄连续可点，移动鼠标不闪烁；调整节点大小不误变画布 zoom。 |
| 滚轮、空格/中键平移、控件缩放与适应视图 | 内容/菜单/面板优先自身滚动；空白连续缩放以指针为锚，范围 0.1–4；平移不编辑正文。适应视图避让面板且包含目标节点。 |
| 小地图点击/拖动、开关，与画布缩放交叉操作 | 地图定位以视口中心为准；边界正确，无越界视口框/跳动；自身滚轮不缩放画布，面板打开不遮挡地图。 |
| 默认/窄/最大化窗口，左右面板分别/同时打开，深浅主题 | 顶栏和面板无多余空白断层、重叠；控件可见可点，面板不遮顶栏；节点在画布/面板边缘时菜单不裁切，胶囊可翻转或定位到可操作区域。 |
| 撤销/重做、整理、聚焦、锁定、主题、小地图按钮 | tooltip、禁用/按下状态与实际一致；锁定保护结构操作，解锁可继续；整理不丢数据。 |
| 导入/导出、复制粘贴、文件拖入、保存退出重开 | 操作结果可再次读取，六类节点、连线、分组、运行结果和内容关联保留；退出无未保存数据静默丢失。 |
