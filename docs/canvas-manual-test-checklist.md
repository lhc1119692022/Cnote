## 准备

- 使用测试画布副本，不在唯一一份重要文档上做删除、刷新或异常退出测试。
- 重启并使用包含本次改动的版本；仅刷新旧安装包不会自动更新代码。
- 准备文本、图片/表格、AI、生成、浏览器、贴纸和编组，至少一组上游输入与下游结果连线。先测约 30 节点，稳定后再测 100/300 节点。
- 真实 AI/生成测试可能消耗用户渠道额度；可先用已有结果做引用检查。自动测试仅使用本地夹具，未调用收费服务。
- 每行记录通过、部分完成、失败或未测及其边界；失败时附操作步骤、节点类型、缩放比例、窗口/DPI、是否正在输出和截图/录屏。不要仅记录“卡了”。
