# 使用流程问题：交付与手动验收（更新于 2026-09-18）

## 本批范围与验证边界

对应前一批八张截图，以及 9 月 18 日的模型拉取、上游图片、便签和两项批注。本批已修改并完成基础自动检查，不代表整个旧版兼容计划已完成。

按照用户的新要求，本批不启动或控制电脑进行桌面操作。下表全部是交给用户执行的手动验收，尚未标记通过。AI 自动测试使用本地模拟响应，不访问网络、不读取真实密钥、不产生费用。

## 追加验收：Markdown 回复与统一生成按钮

本轮仍只做代码和模拟回归，不启动桌面，不调用真实生成渠道。

| 操作 | 通过标准 |
| --- | --- |
| 查看包含标题、粗体、列表、代码块、表格的 AI 回复；再打开右侧详情 | 两处均按 Markdown 排版，不再直接显示格式标记；用户问题保持原样；回复不能编辑，没有格式工具栏。旧会话中的 Markdown 回复同样渲染，复制回复仍保留原始 Markdown。 |
| 在图片和视频生成节点中开始一个任务，随后移开鼠标 | 输入框右下角只有一个主操作按钮，显示“生成中”和递增的已等待时间；普通状态仍是原来的图标按钮。 |
| 将鼠标移入正在生成的主按钮，然后移开 | 悬停时底色红色、文字改为“取消生成”；移开恢复“生成中”和时间，切换文字不挤动按钮。键盘聚焦也显示取消操作。点击后走原有取消流程。 |
| 有暂停任务时离开再返回画布，或重开已保存的 Flow | 同一位置显示带文字的“继续生成”，没有独立的继续/取消按钮。点击恢复原任务，不新建重复任务；恢复后回到生成中状态。暂停期间即使提示词被清空，继续按钮仍按任务快照恢复。 |
| 不想恢复暂停任务 | 参数菜单仍提供“放弃暂停任务”，但不占用输入框主操作行。 |

计时沿用任务的提交时间，因此退出期间已经等待的时间不会归零。桌面实机、真实取消和恢复结果仍待用户验证。

## 本轮优先验收（2026-09-18）

以下项目均为待用户桌面手测，不代表已经通过实机验收。模型列表由站点实际支持的接口和账户权限决定；模型列表成功不等于已验证图片/视频生成任务。

| 操作 | 通过标准 |
| --- | --- |
| 图片/视频渠道分别拉取模型；再编辑未保存的 Key 后拉取 | 能显示站点返回的模型；不再出现“authorization 必须通过 SecretStore 引用”。若站点返回鉴权/接口错误，应显示该错误，不能伪装成成功或自动启用预设模型。未保存的 Key 不覆盖原渠道。 |
| 保存渠道、关闭再打开配置，Key 留空，拉取模型 | 使用原渠道保存的密钥正常请求；Google 原生图像渠道使用原生模型列表，兼容站点使用兼容列表。 |
| 导入一张有清晰可辨内容的 PNG/JPEG，连到支持识图的 AI；不插入胶囊直接提问 | 回答体现图片内容，而非仅凭文件名推测。正文节点一起连接时，正文也能被引用。 |
| 新建 AI 会话，将图片胶囊插入输入框后提问 | 同样能够识图；重复插入同一图片胶囊不重复发送图片。显式胶囊按引用选择上游；没有胶囊时自动使用所有直接上游。 |
| 多图内容切换当前图片再提问；正常退出并重新打开 Flow 后再问 | 发送当前选中的图片；本地图片通过持久资源重新读取，不向渠道发送过期 blob 地址。资源丢失时明确报错，不只发送文件名后假装正常。 |
| 创建便签，悬停并从顶部胶囊切换颜色；撤销、重做 | 色点只在胶囊，节点正文没有颜色行；选中色明确；撤销/重做恢复颜色。锁定画布时色点不可更改。 |
| 编辑便签，并查看普通文本节点格式工具 | 便签只保留撤销、重做、粗体、斜体、无序列表、任务列表，正常尺寸一排；已有正文格式保留。普通文本节点仍有完整格式工具。 |
| 在 25%、50%、100%、150%、250% 缩放和平移画布 | 背景点大小、点间距、屏幕位置不随画布变换改变；浅色/深色仍可见。 |
| 空白左键双击打开菜单 | 第一组依次为“添加内容节点、添加 AI 节点、添加请求体、添加浏览器节点”；第二组为“添加贴纸、导入文件”；第三组为“内容资料库”。只有两条组间分隔线，名称无多余“节点”或数量。 |

## 开始前

1. 正常保存并关闭已经打开的旧 Cnote 窗口。
2. 通过项目根目录的 start-cnote.bat 启动当前代码，避免旧窗口仍使用旧构建。
3. 新建一个测试 Flow，先使用 100% 缩放。之后把关键检查重复在 50%、150% 和窄窗口下进行。
4. 基础布局检查不需要任何模型渠道。真实聊天和生成只使用你自己确认可用的渠道与模型。

## 按实际操作顺序检测

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 空画布小地图 | 新建空 Flow；依次打开/关闭左面板和右面板 | 视口框中心位于小地图中心，四周有留白，不再贴角。放置节点后，小地图转为围绕节点范围导航，不要求视口框永远居中。 |
| 2 点状背景 | 在空白处缩放、平移；切换浅色/深色 | 可见点状网格；点大小、间距和屏幕位置固定，不随画布缩放和平移改变。 |
| 3 双击创建 | 用左键双击空白处；从菜单创建节点；再在编辑器、节点标题、工具栏上双击 | 空白双击出现添加菜单，新节点出现在所点位置附近；菜单靠边不出屏幕；按 Escape 或点外部可关闭；节点内双击不误弹画布菜单。 |
| 4 左栏顶部 | 打开左侧节点面板，再同时打开右侧详情面板 | 左栏上边缘与顶栏/右面板保持同一顶部留白，不再多留一条顶栏高度的空白；顶栏按钮仍可用。 |
| 5 圆角 | 创建 Content、AI、Request、Browser、Sticky，选中并在 50%/100%/150% 下查看四角 | 选中外框与内容外轮廓圆角吻合，不出现一大一小两个弧。浏览器在画布缩放后同样吻合。 |
| 6 文本默认收纳 | 创建文本 Content 节点，输入几行文本，点击上方胶囊中的“文本格式设置” | 默认不展示格式工具；点击设置展开，再点收起；内容和已有格式不丢失。工具不足一行时自动换行，无工具栏横向滑块。 |
| 7 文本详情 | 打开该文本节点右侧详情，缩小详情面板宽度；在面板中编辑 | 面板不再套一个带边框的编辑卡片，没有重复“文本”小标题；格式工具自动换行；编辑区域利用剩余面板高度；正文与画布节点同步。 |
| 8 AI 上游与胶囊 | 把文本连到 AI；查看节点上方胶囊和左侧上游标签 | 上游信息标签位于节点左侧外部，不挤占消息区；标签仍能点击或拖入输入框引用。胶囊包含模型选择、会话管理、系统提示词、AI 设置。 |
| 9 AI 设置位置 | 新建 AI 后查看输入框下方；点击“AI 设置”，再关闭 | 默认隐藏输入框下方的联网、思考强度、模型行。展开后联网和思考强度在左侧，模型选择在右侧；胶囊中的模型入口一直可用。收起不会清空选择。部分模型不支持的选项应禁用而非伪装可用。 |
| 10 会话和系统提示 | 打开会话菜单，新建两次会话，切回第一条；重命名其中一条；切换系统提示词按钮 | 菜单能新建、列出并切换本节点会话，能重命名；旧消息不因新建消失；系统提示词可展开编辑和收起，不固定占据节点顶部。 |
| 11 AI 详情聊天 | 选中 AI 并打开右侧详情；先输入但不发送，再按需用实际渠道发送 | 右侧是放大的聊天界面，不是两个配置文本框；两边输入、模型设置、当前会话和消息同步；从一侧发送时另一侧不能重复发送，回复显示在两边。 |
| 12 请求体入口 | 新建两个请求体，分别点“图片生成”和“视频生成” | 请求体仅显示选择入口，不再有请求体/图片/视频三页标签；选择后分别形成独立图片生成和视频生成节点，不再通过标签切换成另一种类型；节点标题匹配类型，自定义标题保留。 |
| 13 生成输入区 | 分别查看图片/视频生成节点，输入提示词，打开模型/参数菜单 | 模型及参数控件位于底部输入框内部左下方，与右侧发送按钮处于同一操作行；视频模式同样在该区域；原输入框左侧无意义的图片/视频小图标消失。引用素材入口仍保留，不要将它误认为已删除的小图标。 |
| 14 菜单与缩放 | 把 AI/生成节点移到画布底部和右侧，打开模型或参数菜单；尝试窄窗口和详情面板 | 菜单在必要时向上/向内放置，不被正文或面板剪掉；滚动菜单不缩放画布；点击参数不拖动节点。 |
| 15 保存重开 | 保存测试 Flow，正常退出并重开 | 节点类型、文本、模型配置、会话及其名称/消息、连线保留。格式/AI 设置的展开状态是界面状态，新启动默认收纳，不算内容丢失。 |

## 实现约束

请求体、图片生成、视频生成通过现有 request 声明的 variant 区分；用户界面不再把它们显示成可互相切换的标签页。保留现有运行时、生成结果关联、绝对坐标以及历史参数，不通过更换节点 ID 或清空已有结果制造“独立节点”。

旧会话如果已有本节点的 activeSessionId，会按原关联继续展示；新建会话明确记录运行时 nodeId，以便切换和重启后查找。没有归属信息的历史孤立会话不会被武断分配给其他节点。
