# 统一存储、画廊与资源回收验收

## 本轮产品规则

- 画布、生成任务和底层资源保持分离；节点复制/拖出不复制媒体文件。生成客户端不再额外把同一份媒体输出到 resources 目录。
- 画廊是现有 Flow 生成结果的索引，不是另一个资料库。相同生成请求中同一资源的多个节点合并显示使用位置；不同请求生成相同字节仍保留不同的生成事件。
- 收藏仅用于筛选，不额外占有资源。资料库和模板引用会阻止自动回收。
- 从某个画布移除只修改该画布；彻底删除是全局动作，会先显示画布、资料库和模板影响范围。批次其他资源保留。外部原文件及服务商远程文件永不由此操作删除。
- 删除 Flow 不立即清空媒体文件：无人使用的资源首次核对进入 7 天保留期；在设置清理或后台后续核对时回收。保留期内重新被使用则解除回收状态。
- 自动回收保护当前撤销历史、其他画布、资料库、模板、聊天和捕获引用。未结束/待继续任务、损坏画布、清理期间使用状态变化会使回收暂缓；正在画布页面时不自动回收。
- 全局删除先持久化清理记录，再处理各使用位置和文件。失败时不宣布完成；后续清理可继续。旧自动保存和撤销不能恢复被彻底删除的资源。明确重新导入同样的文件仍然允许。

## 数据位置

免安装包通过 PORTABLE_EXECUTABLE_DIR 使用程序旁 CnoteData；已有自定义位置优先。安装版首次使用提示选择目录；已有数据保留原位置，用户在设置中主动迁移。

正式数据、浏览器会话/缓存、应用日志、应用临时目录、应用内浏览器下载都归入数据根目录。用户主动导出的文件按用户选择保存；操作系统和免安装启动器自身的临时文件不承诺完全离开 C 盘。安装版仍使用系统应用目录中的一个很小的位置配置文件。

迁移在下次启动、建立会话前执行：只接受空目录，拒绝新旧目录相同/嵌套，检查可用空间，复制正式数据并逐文件校验；浏览器 Cookie 等会话保留，可重建缓存跳过。成功后切换。原目录保留，不自动删除，确认新目录正常后用户自行处理旧备份。数据目录丢失或迁移失败时提示错误，不偷偷回退 C 盘。

注意：迁移很大数据集时，启动校验可能耗时。重启前不要强制结束进程；不要在旧备份确认前删除原目录。

## 手动测试前准备

使用测试 Flow 和可丢弃的生成结果，先备份正式数据。关闭旧桌面进程，通过 start-cnote.bat 启动本轮构建。全局彻底删除不可撤销，请不要用重要作品试验。

## 测试清单和通过标准

### 1. 数据目录迁移

1. 创建一个测试 Flow，放入图片/视频，保留聊天记录及一个浏览器登录会话。
2. 设置 → 存储：记录当前位置及媒体、文档、缓存占用。
3. 选择另一磁盘的空文件夹，点击迁移。重启前继续编辑一段文本，再正常重启。
4. 通过：新位置成为当前位置；重启前最后的文本、图片、视频、会话仍在；旧目录保留；再次重启仍使用新位置。
5. 拒绝场景：非空目录、当前目录的子目录、无写权限目录。通过：清晰报错、不覆盖现有文件、不丢失原数据。
6. 可选故障场景仅使用测试目录：退出后暂时改名自定义目录，再启动。通过：明确报错，不显示另一个空数据库或退回默认目录；恢复名称可正常启动。
7. 分别用安装包和免安装包检查首次位置提示/默认目录；开发启动不能替代这两种打包验证。

### 2. 缓存与空间

1. 浏览网页、打开画廊并加载预览，刷新存储占用。
2. 点击清理缓存。通过：缓存下降或可重新生成；Flow、原图、视频和浏览器登录信息保留。
3. 重复拖出同一图、多次复制节点。通过：节点增加，但媒体文件占用不应随副本数量成倍增加。
4. 浏览器下载应进入数据目录 downloads；用户主动另存为仍使用所选位置。

### 3. 画廊浏览

1. 在两个 Flow 分别生成图片和视频，含一批多张结果。
2. 返回主页面 → 画廊。通过：图片/视频分别显示，默认最新在前，排序按钮切换最早优先，批次结果逐项展示。
3. 将同一个结果拖出副本或复制到另一画布。通过：同一次生成不因节点复制重复增加条目，使用位置能列出并跳转。
4. 超过 24 项时翻页；播放视频需要主动点击。通过：不会同时自动播放全部视频，分页/滚动可以持续操作。
5. 收藏、只看收藏、取消收藏、关闭重启。通过：收藏状态保持，不产生新文件。
6. 使用位置 → 跳转。通过：进入正确 Flow，选中目标节点；批次选中对应图片，而不是默认第一张。

### 4. 局部移除与画布删除

1. 同一结果在 A、B 两个画布使用，从画廊的使用位置选择“从此画布移除”A。
2. 通过：A 中相关位置消失，B 正常；文件仍存在；没有被标记全局删除。
3. 删除 A Flow。通过：B 和资料库里的引用不受影响，重启后 A 不重新出现。
4. 删除最后一个使用位置后清理未使用资源。通过：先显示保留期，不立刻丢失可撤销素材；不要通过修改系统时间测试。
5. 7 天回收边界由模拟时钟脚本覆盖，长期实际回收另作观察；资料库/模板仍引用的文件不得被回收。

### 5. 全局彻底删除

1. 建立两画布共享图，另有一个批次含此图及其他图。
2. 点击画廊的彻底删除。通过：确认框列出受影响画布及节点数、资料库与模板数量，明确不可撤销。
3. 确认后：独立使用节点消失，批次只移除此图，其余图可显示；相关边更新；其他不相关节点不变。
4. 切换画布、撤销、重做、退出重开。通过：被删资源不复活；其他编辑历史尽可能保留。
5. 生成中或待继续时尝试清理。通过：拒绝并提示先结束任务，不取消任务、不删输入。
6. 重新导入同样的原文件。通过：作为明确的新导入仍然可用。
7. 网络链接资源：删除只移除 Cnote 使用关系和本地托管文件，不删除服务商或外部磁盘文件。

## 自动检查范围

- web: typecheck、lint、verify-resource-library（含真实 Gallery 组件分页/筛选/收藏，以及生产存储逻辑的模拟字节存储）。
- desktop: build:all、typecheck、verify-data-directory（临时目录与模拟 Electron app；复制校验、嵌套/非空/目录丢失、重启迁移、原数据保留）、test:runtime。
- 原有画布、生成、会话退出、运行持久化、AI、浏览器、富文本等回归继续执行。
- 不发送付费请求，不启动或控制用户桌面。安装包、免安装包、真实浏览器会话与大型目录性能需按上面清单人工验证。
